`SDFT`，全称是 `Self-Distillation Fine-Tuning`。它讨论的是一个很现实的问题：大模型已经在通用预训练和指令微调后具备了大量能力，但我们仍然希望继续给它补充新领域、新任务、新偏好。普通 SFT 可以让模型快速学会新数据，却容易破坏旧能力；而 SDFT 的核心想法是，在学习新数据时，把模型自己原本的行为也当作一种约束，从而缓解遗忘。

## 一、问题背景：SFT 为什么容易遗忘

指令微调通常可以写成一个很熟悉的最大似然目标。给定训练数据：

{{< rawhtml >}}
$$
\mathcal{D} = \{(x_i, y_i)\}_{i=1}^{N}
$$
{{< /rawhtml >}}

模型参数为：

{{< rawhtml >}}
$$
\theta
$$
{{< /rawhtml >}}

普通 SFT 的目标是最大化标注答案的条件概率：

{{< rawhtml >}}
$$
\max_{\theta}
\sum_{(x,y)\in \mathcal{D}}
\log \pi_{\theta}(y|x)
$$
{{< /rawhtml >}}

这个目标很直接：让模型在新数据上更像标注答案。但它没有显式关心模型原本会怎么回答，也没有显式约束旧任务上的行为。因此当新数据分布比较窄、训练轮数较多，或者学习率偏大时，模型会逐渐把概率质量挪到新数据偏好的区域。

这就是持续学习里的典型 `catastrophic forgetting`：模型在新任务上变好，但旧能力下降。

在大模型后训练里，这个问题尤其明显。原因不是模型太小，而是 SFT 的监督信号太硬：

- 每个位置只鼓励标注 token。
- 标注答案之外的大量合理 token 会被相对压低。
- 新数据覆盖不到的旧行为没有保护机制。
- 训练越充分，模型越可能朝着新数据的局部分布过拟合。

SDFT 试图在不保留旧任务数据、不额外引入外部 teacher 的情况下，给 SFT 加一个“别偏离自己太远”的约束。

## 二、SDFT 的核心思路

SDFT 的名字里有两个关键词：`self-distillation` 和 `fine-tuning`。

这里的 `self` 指的是 teacher 不是另一个更大的模型，而是 fine-tuning 之前的模型副本。设初始模型为：

{{< rawhtml >}}
$$
\pi_{\theta_0}
$$
{{< /rawhtml >}}

训练中的模型为：

{{< rawhtml >}}
$$
\pi_{\theta}
$$
{{< /rawhtml >}}

SDFT 一边让当前模型学习新数据的标准答案，一边让当前模型在同一批输入上不要过度偏离初始模型的 token 分布。直观上可以理解为：

> 新答案要学，但原模型的语言习惯、推理偏好和通用能力不要轻易抹掉。

因此，SDFT 的目标可以粗略拆成两部分：

{{< rawhtml >}}
$$
\begin{aligned}
\mathcal{L}_{SDFT}
&= \mathcal{L}_{SFT} + \lambda \mathcal{L}_{SD}
\end{aligned}
$$
{{< /rawhtml >}}

其中：

- `SFT loss` 负责学习新数据。
- `Self-distillation loss` 负责保留初始模型的行为分布。
- `lambda` 控制新知识学习和旧能力保持之间的权衡。

如果 `lambda` 太小，SDFT 会退化得接近普通 SFT，遗忘问题仍然明显；如果 `lambda` 太大，模型会过分保守，新任务学习不足。

## 三、训练信号：不只是拟合答案

普通 SFT 在每个 token 位置上只看标注答案：

{{< rawhtml >}}
$$
-\log \pi_\theta(y_t | x, y_{<t})
$$
{{< /rawhtml >}}

而自蒸馏会额外比较当前模型和初始模型在同一上下文上的分布。常见写法是 KL 约束：

{{< rawhtml >}}
$$
D_{KL}
\left(
\pi_{\theta_0}(\cdot | x, y_{<t})
\Vert
\pi_{\theta}(\cdot | x, y_{<t})
\right)
$$
{{< /rawhtml >}}

把它加到逐 token 的训练目标里，可以得到类似下面的形式：

{{< rawhtml >}}
$$
\begin{aligned}
\mathcal{L}_{SDFT}
&= -
\sum_t
\log \pi_\theta(y_t | x, y_{<t}) \\
&\quad +
\lambda
\sum_t
D_{KL}
\left(
\pi_{\theta_0}(\cdot | x, y_{<t})
\Vert
\pi_{\theta}(\cdot | x, y_{<t})
\right)
\end{aligned}
$$
{{< /rawhtml >}}

这和普通 SFT 的差别非常关键。

SFT 只告诉模型：“这个 token 应该更高。”

SDFT 还告诉模型：“在提升标注 token 的同时，不要把原来合理的分布结构全部打乱。”

这种约束对 LLM 很有意义。因为语言生成里常常存在多个合理答案，标注答案只是其中一种轨迹。如果只用 one-hot token 做监督，模型会把许多原本合理但未被标注的表达方式当成负样本；自蒸馏则保留了初始模型对这些候选 token 的软偏好。

## 四、为什么它能帮助持续学习

持续学习的困难在于：新任务数据只覆盖了局部行为，但参数更新会影响全局模型。

SDFT 的自蒸馏项相当于在新数据附近加入一个行为正则项。它不要求模型在所有旧任务上完全不变，因为那样会阻碍学习；它只要求模型在当前训练上下文中保留一部分原始分布结构。

可以从三个角度理解它的作用。

### 4.1 保留暗知识

初始模型的输出分布里包含很多 `dark knowledge`。例如在某个位置上，标注 token 是最高概率，但第二、第三候选 token 的相对顺序也反映了模型已经学到的语义、语法和任务偏好。

普通 SFT 只看标注 token，忽略这些相对关系。SDFT 通过分布级约束保留这些信息，因此更新更平滑。

### 4.2 限制参数漂移

SDFT 不直接约束参数：

{{< rawhtml >}}
$$
\|\theta - \theta_0\|
$$
{{< /rawhtml >}}

而是约束模型行为：

{{< rawhtml >}}
$$
\pi_{\theta}(\cdot | s) \approx \pi_{\theta_0}(\cdot | s)
$$
{{< /rawhtml >}}

这里的 `s` 是上下文状态。行为约束通常比参数约束更贴近生成质量，因为大模型存在大量参数冗余：参数变化不一定代表行为变化，参数不变也不一定保证输出分布稳定。

### 4.3 把新任务学习变成保守更新

SFT 是“向标注答案靠近”；SDFT 是“向标注答案靠近，但尽量沿着原模型能接受的方向靠近”。

这使得模型不会为了新任务把原有分布剧烈重塑。对于连续接入多个任务、多个领域数据的场景，这种保守更新更符合持续学习需求。

## 五、论文里的 IRL 视角

论文还从 `Inverse Reinforcement Learning`，也就是逆强化学习角度解释 SDFT。

如果把语言模型看成一个策略：

{{< rawhtml >}}
$$
\pi_{\theta}(y_t | x, y_{<t})
$$
{{< /rawhtml >}}

那么 SFT 可以理解为从专家轨迹中学习行为。问题是，专家轨迹只告诉我们“做了什么”，不直接告诉我们“为什么这么做”。IRL 的思想则是从专家行为中反推出隐含奖励函数。

在这个视角下，初始模型本身可以看成已经编码了一套隐含奖励或偏好。SDFT 的自蒸馏项相当于保留这套隐含偏好，同时用新数据修正它。

这解释了为什么 SDFT 不需要旧任务数据也能缓解遗忘：它不是显式重放旧样本，而是通过初始模型的分布把旧能力压缩成一种软约束。

这也解释了它的局限：如果初始模型本身在新任务上很差，或者新任务要求明显违背原模型偏好，那么过强的自蒸馏会拖慢学习。

## 六、和几类方法的关系

### 6.1 SDFT vs SFT

SFT 是单目标学习：

{{< rawhtml >}}
$$
\text{fit new labels}
$$
{{< /rawhtml >}}

SDFT 是双目标学习：

{{< rawhtml >}}
$$
\text{fit new labels} + \text{preserve old behavior}
$$
{{< /rawhtml >}}

因此 SDFT 更适合持续学习、领域增量学习、偏好微调后的继续训练等场景；如果只追求单一新任务上的极致拟合，普通 SFT 可能更激进。

### 6.2 SDFT vs 外部 teacher 蒸馏

传统知识蒸馏通常有一个更强 teacher：

{{< rawhtml >}}
$$
\pi_T
$$
{{< /rawhtml >}}

学生模型学习 teacher 的分布。SDFT 的 teacher 则是自己过去的版本：

{{< rawhtml >}}
$$
\pi_{\theta_0}
$$
{{< /rawhtml >}}

这带来两个好处：

- 不需要额外准备更大 teacher。
- teacher 和 student 的 tokenizer、能力边界、输出风格天然一致。

但代价也很清楚：SDFT 的 teacher 不会凭空提供超出初始模型太多的新能力，它主要提供稳定性，而不是上限提升。

### 6.3 SDFT vs replay

持续学习里常见方法是 replay：保留一部分旧任务数据，在新任务训练时混合重放。

SDFT 不依赖旧数据，更适合旧数据不可用、隐私受限、数据版权复杂的场景。但如果旧任务评测非常关键，replay 仍然是强基线。实际工程里，两者并不冲突：可以用少量 replay 数据保护关键能力，同时用 SDFT 约束模型整体行为。

### 6.4 SDFT vs OPD

SDFT 和 `On-Policy Distillation` 都涉及蒸馏，但关注点不同。

OPD 通常强调 student 自己 rollout，在 student 真实访问到的状态上向 teacher 学习。它解决的是 teacher 轨迹和 student 推理轨迹不一致的问题。

SDFT 更强调持续学习中的稳定性。它的 teacher 是初始模型，核心问题不是“如何从更强 teacher 学到更多”，而是“如何在学新任务时少忘旧能力”。

可以粗略理解为：

- OPD 偏向提升学生在生成轨迹上的学习有效性。
- SDFT 偏向控制继续微调时的行为漂移。

## 七、实验现象如何理解

论文的主要结论可以概括为：在连续学习设置下，SDFT 相比普通 SFT 能更好地维持旧任务表现，同时保持对新任务的学习能力。

这个结论并不意外，但有两个细节值得注意。

第一，SDFT 的收益来自软分布，而不是简单冻结。冻结参数当然也能减少遗忘，但它会降低新任务学习能力。SDFT 的目标是在可学习和可保持之间做连续权衡。

第二，SDFT 不是万能的。它保护的是初始模型已经会的东西。如果后续任务和初始模型差异很大，自蒸馏项会形成阻力。此时更关键的是调节 `lambda`、训练步数、学习率，以及是否混入少量目标领域高质量数据。

## 八、实践配方

如果要把 SDFT 用到自己的 LLM fine-tuning 流程里，我会优先关注下面几个点。

### 8.1 保留一份 frozen reference model

训练前复制一份初始模型作为 reference：

{{< rawhtml >}}
$$
\pi_{\theta_0}
$$
{{< /rawhtml >}}

训练时它只做前向推理，不参与梯度更新。当前模型则同时接受 SFT loss 和 distillation loss。

实现上这会增加显存和计算开销。对于大模型，可以考虑：

- reference model 使用推理模式。
- 开启 KV cache 或 logits 缓存。
- 只在部分 token 或 top-k token 上计算蒸馏。
- 使用 LoRA / QLoRA 降低当前模型训练成本。

### 8.2 蒸馏位置不要盲目全开

全词表 KL 信息最完整，但成本高。实际中可以根据预算选择：

- full-vocabulary KL：质量最好，成本最高。
- top-k KL：在 teacher 或 student 的 top-k token 上约束，成本较低。
- sampled-token KL：最省，但信号最窄。

如果训练资源有限，top-k 通常是更现实的折中。

### 8.3 把 lambda 当成核心超参

`lambda` 控制学习和保持的平衡。

经验上可以按任务性质调节：

- 新任务和原模型能力接近：`lambda` 可以稍大，重点减少遗忘。
- 新任务明显偏领域化：`lambda` 不宜过大，否则会学不进去。
- 数据量很小：适当增大 `lambda`，防止过拟合。
- 数据质量很高且目标明确：可以降低 `lambda`，让模型更充分适配。

### 8.4 用旧能力评测集监控

SDFT 的目标是持续学习，因此不能只看新任务分数。至少应该同时看：

- 新任务验证集表现。
- 通用指令跟随能力。
- 推理、数学、代码等核心能力。
- 安全性和拒答边界。
- 输出风格是否出现异常漂移。

如果新任务分数上升但通用能力快速下降，说明蒸馏约束不够；如果旧能力稳定但新任务学不动，说明约束太强或训练信号不足。

## 九、局限与注意事项

SDFT 的优点是简单、稳定、无需旧数据，但它也有明显边界。

第一，它不能替代高质量数据。自蒸馏只能保护旧能力，不能修复新数据本身的问题。如果新数据噪声大，SDFT 只是让模型更稳定地学习噪声。

第二，它会增加训练成本。每个 batch 都需要 reference model 提供 logits，计算量接近额外做一次前向。

第三，它可能限制迁移幅度。当新任务要求模型显著改变风格、格式或策略时，reference model 的分布会变成阻力。

第四，它依赖初始模型质量。初始模型越强，reference 分布越有价值；初始模型本身能力不足时，自蒸馏保留下来的也可能是旧错误。

## 十、总结

SDFT 可以看成一种非常朴素但有效的持续学习方法：**继续微调时，不只学习新答案，也保留旧模型的软分布。**

它的关键价值不是让模型凭空获得更强能力，而是让后训练过程更稳。对于需要持续接入新任务、新领域、新偏好的大模型系统来说，这一点很重要。

一句话概括：

> SFT 负责让模型学新东西，SDFT 负责让模型学新东西时不要忘得太快。
